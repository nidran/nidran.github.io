Gradient Descent

Say it in 30s: An iterative optimizer. Compute the gradient of the loss with respect to the parameters, then step in the negative gradient direction. Repeat. The learning rate sets the step size. It converges to a stationary point of differentiable losses (the global minimum if the loss is convex) without solving for it in closed form.

Variants

  • Batch GD: gradient over the whole dataset each step — stable, slow, memory-heavy.
  • SGD: one example (or mini-batch) at a time — noisy but fast, and the noise can help escape sharp minima.
  • Mini-batch SGD: the practical default.
  • Momentum / Adam / RMSProp: adapt the step using past gradients to go faster and handle ill-conditioning.

The one update step: w ← w − η · ∂L/∂w. For linear regression with MSE, ∂L/∂w = (2/n) Xᵀ(Xw − y).

Traps

  • Learning rate too high → diverge; too low → crawl.
  • Non-convex losses (neural nets) → only convergence to a stationary point (often a saddle or plateau), not a global minimum; that's usually fine in practice.
  • Always scale/standardize features so the loss surface isn't a stretched ravine.
