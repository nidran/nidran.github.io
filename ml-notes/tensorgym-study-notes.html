TensorGym Study Notes

A cheat-sheet of the concepts covered while working through the TensorGym exercises (Colab notebook).

#Tensors & axes

#dim — which axis the operation runs along

The number you pass to sum, mean, max, softmax, etc. is the axis that gets collapsed. For a 2D tensor of shape [rows, cols]:

  • dim=0 → travel down the rows → one result per column
  • dim=1 → travel across the columns → one result per row
x = torch.tensor([[1., 2, 3], [4, 5, 6]])   # shape [2, 3]
torch.sum(x, dim=0)   # [5, 7, 9]   (per column)
torch.sum(x, dim=1)   # [6, 15]     (per row)

Rule of thumb: if the answer should have one number per column, use dim=0; per row, dim=1.

#keepdim=True — preserve the collapsed axis as size 1

Keeps shape [2, 1] instead of [2] so it broadcasts back against the original.

m = torch.max(x, dim=1, keepdim=True).values   # shape [2, 1]
x - m   # works element-wise per row thanks to broadcasting

#squeeze / unsqueeze — remove / add a size-1 dimension

v = torch.tensor([1, 2, 3])   # [3]
v.unsqueeze(1)                # [[1],[2],[3]]  shape [3, 1]  (column vector)
v.unsqueeze(0)                # [[1, 2, 3]]    shape [1, 3]  (row vector)

y = torch.tensor([[1],[2],[3]])  # [3, 1]
y.squeeze()                      # [1, 2, 3]   shape [3]

squeeze only removes dimensions of size 1. keepdim=True is like a built-in unsqueeze.

#argmax — index of the max, not the value

a = torch.tensor([10, 50, 30])
torch.max(a)     # 50  (the value)
torch.argmax(a)  # 1   (the position). Ties -> first occurrence.

Same in NumPy. With a dim/axis it returns the argmax along that axis.

#torch.cat — join tensors along an axis

torch.cat((A[:, :i], A[:, i+1:]), dim=1)   # drop column i (join left & right blocks)

dim=1 joins side-by-side (columns); dim=0 stacks vertically (rows). @ is shorthand for torch.matmul.

#dtype gotcha

Integer literals make int tensors. mean/var error on int tensors, and mixed-dtype matmul fails. Cast with x = x.float() up front when inputs come from integer lists.

#Math foundations

#Variance: population (/N/N/N) vs unbiased (/(N−1)/(N-1)/(N−1))

torch.var(x)                    # default: / (N-1)  "unbiased" (Bessel's correction)
torch.var(x, unbiased=False)    # / N               "population"

Manual: 1N∑(x−xˉ)2\frac{1}{N}\sum (x - \bar{x})^2N1​∑(x−xˉ)2 (population) or divide by N−1N-1N−1 (unbiased). Use population when your data is the whole set (batch norm, standardize); N−1N-1N−1 when estimating from a sample.

#Z-score standardization (per feature/column)

xstd=x−μσ2+ϵx_{\text{std}} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}xstd​=σ2+ϵ​x−μ​
mean = x.mean(dim=0, keepdim=True)
var  = x.var(dim=0, unbiased=False, keepdim=True)
x_std = (x - mean) / torch.sqrt(var + 1e-8)   # 1e-8 for numerical safety

#Neural-network building blocks

#Softmax (turns logits into a probability distribution)

A logit = raw, unbounded model score before normalization. On paper, softmax(z)i=ezi∑jezj=ezi−m∑jezj−m\text{softmax}(z)_i = \dfrac{e^{z_i}}{\sum_j e^{z_j}} = \dfrac{e^{z_i - m}}{\sum_j e^{z_j - m}}softmax(z)i​=∑j​ezj​ezi​​=∑j​ezj​−mezi​−m​ with m=max⁡jzjm = \max_j z_jm=maxj​zj​ (log-sum-exp trick; same probabilities, no overflow).

Broadcasting: trailing dimensions align right; size-1 axes stretch. Hence keepdim=True after max/mean so [B,1] subtracts from [B,C]. Batched matmul: [B,n,m] @ [B,m,p] → [B,n,p].

m = logits.max(dim=1, keepdim=True).values   # subtract max for numerical stability
e = torch.exp(logits - m)
probs = e / e.sum(dim=1, keepdim=True)        # each row sums to 1

The max-subtraction does not change the result (softmax is shift-invariant) — it just prevents exp overflow.

Cross-entropy from logits: L=−log⁡py=−zy+m+log⁡∑jezj−mL = -\log p_y = -z_y + m + \log\sum_j e^{z_j - m}L=−logpy​=−zy​+m+log∑j​ezj​−m; F.cross_entropy(logits, y) fuses this (don't softmax then log).

#Sigmoid & logistic regression

σ(z)=11+e−z\sigma(z) = \dfrac{1}{1 + e^{-z}}σ(z)=1+e−z1​ squashes any real zzz to (0,1)(0, 1)(0,1); a logit of 0 → probability 0.5.

logits = X @ w + b
probs  = torch.sigmoid(logits)        # 1 / (1 + e^-z)
preds  = (probs >= 0.5).float()       # threshold for class labels

#Normalization layers (normalize activations, not weights)

All re-center/re-scale the values flowing between layers; they differ in what they average over:

Method Averages over Batch-size dependent?
Batch norm the batch, per feature (dim=0) Yes — noisy for tiny batches
Layer norm all features of one example No — used in transformers
Group norm feature groups, per example No

Batch norm (across the batch / rows):

mean = data.mean(dim=0)
var  = data.var(dim=0, unbiased=False)  # BN uses the biased (N) variance
out  = (data - mean) / torch.sqrt(var + epsilon)

The mean/var are statistics computed from data each pass — not learned. Only the weights and the norm's learnable γ\gammaγ (scale) / β\betaβ (shift) are updated by gradient descent. Placement is usually: linear → norm → activation (ReLU).

#Scaled dot-product attention

Attention(Q,K,V)=softmax ⁣(QK⊤dk)V\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)VAttention(Q,K,V)=softmax(dk​​QK⊤​)V
scores  = (query @ key.T) / math.sqrt(query.size(-1))   # size(-1) = d_k, the last dim
weights = F.softmax(scores, dim=-1)                      # each query's weights sum to 1
output  = weights @ value                                # weighted blend of value rows

"Weight the values" = weighted average of the value vectors using the softmax weights. Masked version: set blocked positions to a large negative before softmax so they get ~0 weight:

scores = scores.masked_fill(mask == 0, -1e9)

#LoRA (Low-Rank Adaptation)

Freeze the big base weight; learn only a narrow rank-rrr bottleneck BABABA. Order matters (matrices aren't square): AAA projects down (in → rrr), BBB projects up (rrr → out). Output: Wx+αrBA xW x + \frac{\alpha}{r}BA\,xWx+rα​BAx.

# down-project to size r, then up-project to out
lora = dropout(x) @ A.T @ B.T          # [N,in] @ [in,r] @ [r,out] = [N,out]
output = F.linear(x, W, b) + (alpha / r) * lora

#Algorithms

#MSE loss

mse = torch.mean((pred - target) ** 2)   # squared, averaged over ALL elements -> scalar

#One gradient-descent step (linear regression, MSE)

Gradient: 2NX⊤(Xw−y)\dfrac{2}{N}X^\top(Xw - y)N2​X⊤(Xw−y).

error    = X @ w - y
gradient = (2 / X.shape[0]) * (X.T @ error)
w        = w - lr * gradient

#k-Nearest Neighbors

for each test point:
    dist = np.sqrt(np.sum((train - test_point) ** 2, axis=1))   # sum across FEATURES (axis=1)!
    idx  = np.argsort(dist)[:k]                                 # k closest
    pred = majority_vote(train_labels[idx])

Common bug: forgetting np.sum(..., axis=1) — you need one distance per point, not per feature. Majority-vote options:

np.bincount(labels).argmax()                          # non-neg ints only; smallest label on ties
vals, counts = np.unique(labels, return_counts=True)
vals[counts.argmax()]                                 # general purpose

#K-means clustering

seed centroids from random data points
repeat until centroids stop moving:
    assign each point to nearest centroid (argmin of distances)
    move each centroid to the mean of its assigned points

Result depends on initialization (hence a fixed seed, or run multiple times and keep the best).

#Recurring gotchas

  • dtype: cast int tensors to .float() before matmul / exp / sigmoid / division.
  • axis: per-column ⇒ dim=0; per-row ⇒ dim=1; last dim ⇒ dim=-1.
  • broadcasting: use keepdim=True so reduced tensors line up with the original.
  • variance: torch.var defaults to N−1N-1N−1; pass unbiased=False for population.
  • return what you compute: easy to leave a return None from the skeleton.
  • threshold: spec wording "greater than" = >, "at" = >=.
