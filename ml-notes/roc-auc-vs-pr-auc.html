ROC-AUC vs PR-AUC

Say it in 30s: Both summarize a classifier across all thresholds. ROC plots TPR vs FPR; its AUC is the probability a random positive is ranked above a random negative. PR plots precision vs recall. On imbalanced data, prefer PR-AUC — ROC-AUC looks deceptively good because the huge negative class makes FPR tiny.

Key points

  • ROC-AUC = 0.5 is random, 1.0 is perfect; threshold-independent and class-balance-insensitive (which is both a feature and a bug).
  • PR-AUC baseline is the positive class prevalence, so it honestly reflects rarity.
  • Use ROC-AUC to compare rankers in general; switch to PR-AUC when positives are rare and false positives matter (fraud, retrieval, medical).

The math

At threshold ttt (predict positive if score ≥t\ge t≥t):

TPR=TPTP+FN,FPR=FPFP+TN\mathrm{TPR} = \frac{TP}{TP+FN}, \qquad \mathrm{FPR} = \frac{FP}{FP+TN}TPR=TP+FNTP​,FPR=FP+TNFP​

ROC plots (FPR,TPR)(\mathrm{FPR}, \mathrm{TPR})(FPR,TPR) as ttt sweeps. ROC-AUC =P(s+>s−) + 12P(tie)= P(s_+ > s_-)\,+\, \tfrac12 P(\text{tie})=P(s+​>s−​)+21​P(tie) — the probability a random positive scores above a random negative (Mann–Whitney U/(n+n−)U/(n_+ n_-)U/(n+​n−​)).

Pair count: positive scores {0.9,0.7,0.4}\{0.9, 0.7, 0.4\}{0.9,0.7,0.4}, negative {0.8,0.3,0.1}\{0.8, 0.3, 0.1\}{0.8,0.3,0.1} → 777 of 999 pairs favor the positive → AUC≈0.78\mathrm{AUC} \approx 0.78AUC≈0.78 (random baseline 0.5).

PR-AUC is average precision:

AP=∑n(Rn−Rn−1) Pn\mathrm{AP} = \sum_n (R_n - R_{n-1})\, P_nAP=n∑​(Rn​−Rn−1​)Pn​

Rn,PnR_n, P_nRn​,Pn​ = recall and precision at the nnn-th cut on the ranked list; ΔRn=Rn−Rn−1\Delta R_n = R_n - R_{n-1}ΔRn​=Rn​−Rn−1​ weights each precision by new recall mass.

Baselines: ROC-AUC for an uninformative ranker is 0.5 regardless of prevalence; PR-AUC baseline is prevalence π\piπ — predicting everything/nothing at the true positive rate yields AP≈π\mathrm{AP} \approx \piAP≈π.

Trap: quoting a 0.95 ROC-AUC on a 1%-positive problem can hide poor precision at the operating point — show PR-AUC too.
