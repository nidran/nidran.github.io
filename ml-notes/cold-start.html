Cold Start

Say it in 30s: Cold start is missing interaction history — for new users or new items. Fix users with priors (onboarding, demographics, trending) and exploration until clicks exist. Fix items with content-based signals: metadata, text/image embeddings computed at upload so the item is immediately in ANN retrieval. Pure collaborative filtering fails until impressions accumulate; hybrid systems are mandatory at scale.

Key points

  • Item cold start: content tower produces vi\mathbf{v}_ivi​ before any clicks; same index as warm items.
  • User cold start: popular/trending prior + onboarding interests; ε exploration to learn fast.
  • New creator / tail: re-ranking boosts and coverage metrics so retrieval does not ignore them.
  • Bandits and explore buckets trade short-term CTR for information.

Common follow-ups / traps

  • "Is cold start only a data problem?" → Also architecture: without content embeddings, new SKUs/videos are invisible to CF retrieval.
  • "How do you evaluate?" → Slice offline recall@k on young items; online new-user retention.
