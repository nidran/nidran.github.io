Bias-Variance Tradeoff

Say it in 30s: For squared-error regression, expected test error decomposes exactly into bias² + variance + irreducible noise. Bias is error from wrong assumptions (too simple a model, underfits); variance is error from sensitivity to the training sample (too flexible a model, overfits). Lowering one usually raises the other, so the goal is the sweet spot, not zero of either.

Key points

  • More capacity (deeper tree, higher polynomial degree, less regularization) → lower bias, higher variance.
  • More data lets you afford more capacity without paying as much variance.
  • The dartboard picture: bias = is the cluster centered on the target; variance = how tight the cluster is.
  • The U-curve: total test error falls then rises as complexity grows; minimum = optimal capacity.
  • Modern asterisk: double descent — past the interpolation point, very overparameterized models can improve again.

Common follow-ups / traps

  • "How do you reduce variance?" → more data, regularization, simpler model, bagging/ensembling.
  • "How do you reduce bias?" → richer model, better features, boosting.
  • Don't confuse this with the bias/variance of an estimator in statistics (related, not identical framing).
