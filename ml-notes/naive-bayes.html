Naive Bayes

Say it in 30s: Naive Bayes is a generative classifier: apply Bayes' rule p(y∣x)∝p(y) p(x∣y)p(y \mid x) \propto p(y)\,p(x \mid y)p(y∣x)∝p(y)p(x∣y) with the "naive" assumption that features are conditionally independent given the class, so p(x∣y)p(x \mid y)p(x∣y) factors into a product of per-feature likelihoods. The independence assumption is almost always false, yet the argmax class often survives because errors distort all classes similarly; it's blazing fast, thrives on high-dimensional sparse text, and needs Laplace smoothing for unseen features.

Key points

  • Multinomial NB: word counts (text); Bernoulli NB: binary presence; Gaussian NB: continuous features as normals per class.
  • Trains in one pass — counts and priors — scales to huge vocabularies.
  • Probabilities are usually poorly calibrated (pushed toward 0/1); trust ranking/labels, not raw scores — see Calibration.
  • Strong small-data baseline when assumptions are "directionally" right.

The math

Naive factorization (features conditionally independent given yyy):

p(y∣x)∝p(y)∏j=1dp(xj∣y).p(y\mid x) \propto p(y)\prod_{j=1}^{d} p(x_j\mid y).p(y∣x)∝p(y)j=1∏d​p(xj​∣y).

Log form (stable products):

log⁡p(y∣x)=log⁡p(y)+∑jlog⁡p(xj∣y)−log⁡p(x).\log p(y\mid x) = \log p(y) + \sum_j \log p(x_j\mid y) - \log p(x).logp(y∣x)=logp(y)+j∑​logp(xj​∣y)−logp(x).

Argmax over yyy needs only the first two terms.

Laplace smoothing (categorical feature jjj, value vvv, class ccc): count NjcvN_{jc v}Njcv​, class count NcN_cNc​, vocabulary size VjV_jVj​:

p^(xj=v∣y=c)=Njcv+αNc+αVj.\hat{p}(x_j{=}v\mid y{=}c)=\frac{N_{jc v}+\alpha}{N_c+\alpha V_j}.p^​(xj​=v∣y=c)=Nc​+αVj​Njcv​+α​.

Tiny spam toy: p(spam)=0.4p(\mathrm{spam})=0.4p(spam)=0.4, p(word∣spam)=0.5p(\mathrm{word}\mid\mathrm{spam})=0.5p(word∣spam)=0.5, p(word∣ham)=0.1p(\mathrm{word}\mid\mathrm{ham})=0.1p(word∣ham)=0.1 → log⁡p(spam∣word)∝ln⁡0.4+ln⁡0.5≈−1.61\log p(\mathrm{spam}\mid\mathrm{word}) \propto \ln 0.4 + \ln 0.5 \approx -1.61logp(spam∣word)∝ln0.4+ln0.5≈−1.61 vs ham ln⁡0.6+ln⁡0.1≈−2.81\ln 0.6 + \ln 0.1 \approx -2.81ln0.6+ln0.1≈−2.81 → predict spam.

Common follow-ups / traps

  • "Why does it work if independence is false?" → only needs the correct class to win, not accurate p(y∣x)p(y\mid x)p(y∣x); shared distortion across classes preserves the argmax. See Generative vs Discriminative.
  • "Zero probability problem?" → Laplace (add-one) smoothing on counts.
  • "NB vs logistic regression?" → generative vs discriminative; NB can win with very little data; logistic usually wins with enough data.

See depth: Classification Methods (§4). Related: Logistic Regression, Maximum Likelihood Estimation, Cross-Entropy Loss.
