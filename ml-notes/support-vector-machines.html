Support Vector Machines

Say it in 30s: An SVM finds the decision boundary that separates the classes with the widest possible margin — the hyperplane as far as possible from the nearest points of each class. Those nearest points are the support vectors and are the only ones that define the boundary. The kernel trick lets it draw nonlinear boundaries by computing dot products in a higher-dimensional space without ever building that space.

Key points

  • Boundary is a hyperplane w·x + b = 0; classify with sign(w·x + b), labels coded y ∈ {+1, −1}.
  • Fix the scale so on-margin support vectors satisfy y(w·x + b) = 1 (in the soft margin, violators have y(w·x + b) < 1); then the half-margin is 1/||w||, full margin 2/||w||.
  • Hard margin: minimize ½||w||² s.t. yᵢ(w·xᵢ + b) ≥ 1. Minimizing ||w|| = maximizing the margin.
  • Soft margin (real data): minimize ½||w||² + C·Σξᵢ s.t. yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ, ξᵢ ≥ 0. Slack ξ allows violations.
  • C is the bias-variance knob: large C → punish violations hard (narrow margin, overfit risk); small C → tolerate violations (wider margin, more regularized).
  • Kernel trick: the dual depends on the data only through dot products xᵢ·xⱼ, so replace them with a kernel K(xᵢ, xⱼ) to get a nonlinear boundary cheaply. Common kernels: RBF (Gaussian), polynomial, linear.

Common follow-ups / traps

  • "What's the margin?" → distance from the boundary to the nearest points (1/||w||; full margin width 2/||w||); SVM maximizes it.
  • "Which points matter?" → only the support vectors; far-away points don't move the boundary.
  • "Why does the kernel trick work?" → optimization needs only pairwise dot products, never the explicit high-dimensional features.
  • "What does C do?" → trades margin width against training violations; it's the regularization parameter.
  • Don't say SVM just "draws a boundary" — the defining idea is the maximum-margin boundary.
