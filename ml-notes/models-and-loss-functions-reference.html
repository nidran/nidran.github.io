Models and Loss Functions Reference

#Problem Type → Baseline → Advanced Model

Problem Type Baseline Advanced

Candidate retrieval (rec sys) Matrix factorization (ALS) Two-tower DNN + FAISS ANN

#Wide & Deep (Google, 2016)

  • Wide side: linear model on manually specified feature crosses (you write user_app × search_query)
  • Deep side: embedding + MLP for generalization
  • Limitation: the cross features on the wide side must be hand-engineered
  • When to use: you have strong domain knowledge about which specific interactions matter

#Deep & Cross Network — DCN (Google, 2017) → DCN v2 (2020)

  • Replaces the wide side with a cross network that automatically learns bounded-degree feature interactions
  • DCN v2 uses a matrix-based cross layer (more expressive than the original vector-based one)
  • Reduces (not eliminates) manual cross engineering
  • A strong upgrade over Wide & Deep when you don't know which crosses matter
  • When to use: large feature spaces, ranking problems where you don't know which crosses matter; a strong, common default for ranking, alongside DLRM/DeepFM

#Summary

Wide & Deep  →  DCN  →  DCN v2
(manual crosses)  (auto crosses, vector)  (auto crosses, matrix — best)

#Classification

Binary Cross-Entropy (Log Loss)

L = -[y·log(p) + (1-y)·log(1-p)]
  • Use: click prediction, fraud, any binary label
  • Output: sigmoid → probability
  • Default choice for binary problems

Categorical Cross-Entropy (Softmax Loss)

L = -Σ y_i · log(p_i)
  • Use: multi-class (mutually exclusive), intent detection, NLP classification
  • Output: softmax → probability distribution

Focal Loss

L = -α_t (1-p_t)^γ · log(p_t)     (p_t = probability assigned to the true class)
  • Use: severe class imbalance (fraud, safety, object detection)
  • The (1-p_t)^γ term downweights easy examples (of either class), focuses training on hard examples
  • γ=2 is typical; originated in RetinaNet
  • Often helps when easy negatives dominate; probabilities need recalibration

#Regression

MSE (Mean Squared Error)

L = (y - ŷ)²
  • Penalizes large errors heavily (squared)
  • Sensitive to outliers
  • Use: when large errors are disproportionately bad

MAE (Mean Absolute Error)

L = |y - ŷ|
  • More robust to outliers than MSE
  • Use: when outliers are common and you don't want them to dominate

Huber Loss

L = 0.5(y-ŷ)²           if |y-ŷ| ≤ δ
L = δ·|y-ŷ| - 0.5δ²     otherwise
  • Best of both: MSE for small errors, MAE for large ones
  • Use: default regression loss when you're unsure (bid prediction, ETA)

#Ranking

BPR Loss (Bayesian Personalized Ranking) — pairwise

L = -log(σ(ŷ_pos - ŷ_neg))
  • Pushes score of positive item above negative item
  • Use: implicit feedback (clicks, watches) where you have user-item pairs
  • Common in recommendation systems

Hinge Loss — pairwise

L = max(0, margin - (ŷ_pos - ŷ_neg))
  • Similar to BPR but with a hard margin
  • Use: ranking when you want a minimum score gap

LambdaRank / LambdaMART — listwise

  • Pairwise gradients weighted by the NDCG change from swapping the pair (a listwise-aware heuristic); LambdaMART is the GBDT version
  • Used inside LightGBM/XGBoost for ranking (objective=lambdarank)
  • Use: when you care about the full ranked list quality, not just pairwise order

ApproxNDCG / SoftNDCG — listwise

  • Differentiable approximation of NDCG
  • Used in neural ranking models
  • Use: training neural rankers end-to-end

#Embedding / Contrastive

Triplet Loss

L = max(0, d(anchor, pos) - d(anchor, neg) + margin)
  • Pulls anchor closer to positive, pushes away from negative
  • Use: face recognition, image similarity, early recommendation embedding work
  • Problem: hard to mine good triplets

NT-Xent Loss (SimCLR / Contrastive)

L = -log( exp(sim(z_i, z_j)/τ) / Σ_k exp(sim(z_i, z_k)/τ) )
  • In-batch negatives: all other samples in the batch are negatives
  • τ = temperature (lower = sharper, higher = softer)
  • Use: self-supervised pretraining, two-tower models, sentence embeddings
  • More efficient than triplet loss (no triplet mining needed)

In-Batch Softmax (used in two-tower models)

  • Same idea as NT-Xent but applied to user-item retrieval
  • All other items in batch = negatives for each user
  • Watch out: popular items appear often as negatives → popularity bias in training, correct with logQ correction (subtract log sampling probability from the logits)

#Knowledge Distillation

KL Divergence

L = Σ p(x) · log(p(x)/q(x))
  • Measures how distribution p (teacher soft labels) differs from q (student predictions)
  • Student loss = task loss + α·KL(teacher || student)
  • Use: compressing large models to smaller ones for serving

#Quick Lookup

Situation Loss
Binary, balanced Binary cross-entropy
Binary, imbalanced (fraud, safety) Focal loss
Multi-class Categorical cross-entropy
Regression, clean data MSE
Regression, noisy/outliers Huber or MAE
Pairwise ranking (implicit feedback) BPR loss
Listwise ranking (optimize NDCG) LambdaRank / ApproxNDCG
Embedding learning NT-Xent (in-batch) or Triplet
Model compression KL divergence
Multi-task Weighted sum of per-task losses
