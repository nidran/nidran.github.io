Cross-Entropy Loss

Say it in 30s: The standard loss for classification. It measures the distance between the true label distribution and the predicted probability distribution. For a true class, it's −log(predicted probability of that class) — you're penalized by how surprised the model was about the right answer.

Why it beats MSE for classification

  • It pairs with softmax/sigmoid to give a well-behaved loss (convex in the logits, and in the weights for a linear model such as logistic regression) with strong gradients even when the model is confidently wrong (MSE's gradient vanishes there → slow learning).
  • It's the maximum-likelihood loss under a Bernoulli/categorical model, so it's the principled choice.

Forms

  • Binary: −[y·log p + (1−y)·log(1−p)], paired with sigmoid.
  • Multiclass: −Σ yᵢ log pᵢ, paired with softmax.

Traps

  • Feed logits to the loss (e.g. CrossEntropyLoss in PyTorch already applies softmax) — don't softmax twice.
  • Numerically unstable if you compute log(softmax) naively; use log-sum-exp / built-in fused versions.

See depth: Loss Functions (§2.3–2.4), TensorGym Study Notes. Related: Maximum Likelihood Estimation, Logistic Regression, Gradient Descent.
