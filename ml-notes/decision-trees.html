Decision Trees

Say it in 30s: A decision tree partitions the feature space with a sequence of axis-aligned splits, greedily choosing each split to maximize impurity reduction (Gini or entropy for classification, variance reduction for regression). It's interpretable and handles mixed feature types with no scaling, but a deep tree overfits badly and is unstable — small data changes can reshuffle the whole structure.

Key points

  • Classification splits: minimize weighted Gini G=1−∑kpk2G = 1 - \sum_k p_k^2G=1−∑k​pk2​ or maximize information gain from entropy H=−∑kpklog⁡pkH = -\sum_k p_k \log p_kH=−∑k​pk​logpk​.
  • Regression splits: minimize within-node variance (equivalent to minimizing MSE).
  • Stopping: max depth, min samples per leaf, min impurity decrease; pruning via cost-complexity Rα(T)=R(T)+α∣T∣R_\alpha(T) = R(T) + \alpha \vert T \vertRα​(T)=R(T)+α∣T∣.
  • High capacity → low bias, high variance on a single tree (why ensembles exist).

Common follow-ups / traps

  • "Why is a single tree high variance?" → greedy splits amplify noise; the boundary is discontinuous and sensitive to which points land in which bootstrap-like subsets.
  • "Gini vs entropy?" → usually very similar splits; Gini is faster (no log); neither handles class imbalance in the split criterion itself — use sample weights or a better metric.
  • "Can trees extrapolate?" → No for regression: predictions are leaf means/constants only within training ranges.
