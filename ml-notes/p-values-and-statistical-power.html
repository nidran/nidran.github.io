p-Values & Statistical Power

Say it in 30s: The p-value is P(data at least this extreme∣H0 true)P(\text{data at least this extreme} \mid H_0 \text{ true})P(data at least this extreme∣H0​ true) — how surprising the result is if there is no effect. It is not P(H0 true)P(H_0 \text{ true})P(H0​ true), not the false-positive rate, and not “probability the lift is real.” Power =1−β= 1-\beta=1−β is the chance to reject H0H_0H0​ when a true effect of size δ\deltaδ exists. Underpowered tests miss real wins; overpowered tests chase trivial deltas — pre-register α\alphaα, δ\deltaδ, and nnn before you peek.

Key points

  • Type I (α\alphaα): false alarm — launch when there is no effect. Type II (β\betaβ): miss — fail to launch a real win.
  • Per-arm sample size (two-sample mean or proportion, equal nnn): n≈2 (z1−α/2+z1−β)2 σ2δ2n \approx \frac{2\,(z_{1-\alpha/2}+z_{1-\beta})^2\,\sigma^2}{\delta^2}n≈δ22(z1−α/2​+z1−β​)2σ2​.
  • Use z-test when nnn is large or σ\sigmaσ known; t-test for small-nnn means with estimated variance; bootstrap or Mann–Whitney when normality fails.

The math

Two-sample proportions (pooled-variance zzz under H0 ⁣:p1=p0H_0\colon p_1=p_0H0​:p1​=p0​):

p^pool=x1+x0n1+n0,z=p^1−p^0p^pool(1−p^pool)(1n1+1n0)\hat p_{\mathrm{pool}} = \frac{x_1 + x_0}{n_1 + n_0}, \qquad z = \frac{\hat p_1 - \hat p_0}{\sqrt{\hat p_{\mathrm{pool}}(1-\hat p_{\mathrm{pool}})\bigl(\frac{1}{n_1}+\frac{1}{n_0}\bigr)}}p^​pool​=n1​+n0​x1​+x0​​,z=p^​pool​(1−p^​pool​)(n1​1​+n0​1​)​p^​1​−p^​0​​

95% CI for δ=p1−p0\delta = p_1 - p_0δ=p1​−p0​: (p^1−p^0)±z1−α/2 SE(\hat p_1 - \hat p_0) \pm z_{1-\alpha/2}\,\mathrm{SE}(p^​1​−p^​0​)±z1−α/2​SE, with SE=p^1(1−p^1)n1+p^0(1−p^0)n0\mathrm{SE} = \sqrt{\frac{\hat p_1(1-\hat p_1)}{n_1}+\frac{\hat p_0(1-\hat p_0)}{n_0}}SE=n1​p^​1​(1−p^​1​)​+n0​p^​0​(1−p^​0​)​​.

Power (two-sided test; dominant-tail approximation): for true effect δ\deltaδ and standard error SE\mathrm{SE}SE under the alternative,

power≈Φ ⁣(δSE−z1−α/2)\mathrm{power} \approx \Phi\!\left(\frac{\delta}{\mathrm{SE}} - z_{1-\alpha/2}\right)power≈Φ(SEδ​−z1−α/2​)

Φ\PhiΦ = standard normal CDF; reject when ∣z∣>z1−α/2|z| > z_{1-\alpha/2}∣z∣>z1−α/2​.

Sample size (equal nnn per arm) remains: n≈2 (z1−α/2+z1−β)2σ2δ2n \approx \frac{2\,(z_{1-\alpha/2}+z_{1-\beta})^2\sigma^2}{\delta^2}n≈δ22(z1−α/2​+z1−β​)2σ2​.

Common follow-ups / traps

  • "p = 0.04 — the lift is 4% likely?" → No. State the correct conditional definition and report a confidence interval for δ\deltaδ.
  • "We stopped early because it looked significant" → Peeking inflates Type I error; use a fixed horizon or proper sequential methods.
