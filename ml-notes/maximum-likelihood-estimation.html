Maximum Likelihood Estimation

Say it in 30s: Pick the parameters that make the observed data most probable. Maximize the likelihood (equivalently, minimize negative log-likelihood). Most common losses are NLL in disguise: the assumed noise model determines the loss.

The key insight interviewers want

  • Assume Gaussian noise on a regression target → MLE gives MSE / least squares.
  • Assume Bernoulli/categorical labels → MLE gives cross-entropy / log loss.
  • So "every loss is a hidden assumption about the noise" — the loss is not arbitrary.

MLE vs MAP

  • MLE maximizes P(data | θ).
  • MAP maximizes P(θ | data) ∝ P(data | θ)·P(θ) — adding a prior. A Gaussian prior on weights = L2 regularization; a Laplace prior = L1.
