Mock - For You Feed Recommendations

Prompt: Design the recsys powering the "For You" home feed of a short-video app (TikTok/Reels). ~200M DAU, billions of mostly-fresh videos, ~100ms ranking budget.

See the spine: ML System Design Framework.

#What I covered

  • Objective → got from vague "engagement" to concrete multi-task labels (watch time, like, share, comment).
  • Architecture → multistage; embeddings at upload for freshness.
  • Retrieval → two-tower + ANN; understood decoupled serving after coaching.
  • Cold start → item via content embeddings (unprompted ✅); user via onboarding + trending.
  • Features → named user/item/cross/context families.
  • Bias → identified exposure/feedback bias + position bias.
  • Eval → NDCG offline; A/B on time-spent/DAU online; drift monitoring post-launch.

#What I did well

  • Strong systems intuition — reached multistage + embedding retrieval + freshness largely solo.
  • Connected item cold-start to content embeddings without prompting (real signal).
  • Understood position bias and the feedback loop once prompted.

#Three things holding back a clean staff signal

  1. I circle before committing. Took 3 turns to get from "engagement" → concrete multi-task labels. Reads as fuzzy. Fix: open with the structured answer.
  2. Generic vocabulary. Said "rate videos higher" not "two-tower w/ decoupled serving"; "look at distributions" not "data/prediction drift + retrain cadence." Concepts there — name the canonical component.
  3. Wait to be asked. Bias, guardrails, monitoring should be volunteered, not prompted. Drive the structure myself.

#Drill for next time

Redo this exact prompt solo, hit objective → metrics → architecture → retrieval → ranking → bias → eval → monitoring in one clean pass, naming the canonical component at each step. Time to ~25 min.

  • Search / visual retrieval (embeddings, two-stage)
