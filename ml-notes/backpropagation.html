Backpropagation

Say it in 30s: Backpropagation is reverse-mode automatic differentiation on the network's computational graph: you evaluate the forward pass once, then apply the chain rule backward from the scalar loss to every parameter. For an LLL-layer net with one output loss, reverse mode costs O(1)O(1)O(1) forward + O(1)O(1)O(1) backward passes versus O(L)O(L)O(L) for naive forward-mode per parameter—so it's the standard way to train deep nets.

Key points

  • Each node stores values from the forward pass; backward messages are ∂L∂⋅\frac{\partial L}{\partial \cdot}∂⋅∂L​ multiplied along edges (chain rule).
  • Shared weights (e.g. tied embeddings) sum gradients from all uses.
  • Frameworks (PyTorch) build the graph implicitly; loss.backward() triggers reverse mode. See TensorGym notes for tensors + autograd.
  • Vanishing/exploding gradients are a depth problem of backprop, not a bug in the algorithm—see Vanishing & Exploding Gradients.

Common follow-ups / traps

  • "Why not compute ∂L∂w\frac{\partial L}{\partial w}∂w∂L​ by finite differences?" → Works in tiny nets; O(#params)O(\#\text{params})O(#params) forward passes, unusable at scale.
  • "Is backprop the same as gradient descent?" → No: backprop computes ∇L\nabla L∇L; the optimizer uses it to update weights.

See depth: Training Neural Networks (§Backpropagation). Related: Activation Functions, Loss Functions, Cross-Entropy Loss.
