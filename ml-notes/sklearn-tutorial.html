scikit-learn Tutorial

A complete tabular-ML workflow in one pass: build a leak-free pipeline, validate it, tune it, pick a threshold, calibrate, and save it.

The whole tutorial uses one synthetic dataset with a numeric column that has missing values, two categorical columns and a ~10% positive class, so every step mirrors a real problem.

#0. The mental model

scikit-learn has three kinds of objects, and almost everything is one of them:

Object Key methods Examples
Transformer fit, transform StandardScaler, SimpleImputer, OneHotEncoder
Estimator / model fit, predict, predict_proba LogisticRegression, HistGradientBoostingClassifier
Pipeline the same API as its last step Pipeline, ColumnTransformer

Golden rule: anything that learns from data (means, medians, category lists, a threshold) must be fit on the training portion only. A Pipeline enforces this automatically inside cross-validation.

#1. Make the data

import numpy as np, pandas as pd

rng = np.random.default_rng(0)
n = 3000
df = pd.DataFrame({
    "age": rng.integers(18, 80, n).astype(float),
    "income": rng.lognormal(10, 0.5, n),
    "plan": rng.choice(["free", "pro", "team"], n, p=[.6, .3, .1]),
    "country": rng.choice(["US", "IN", "DE", "BR"], n),
})
df.loc[rng.random(n) < .1, "income"] = np.nan          # inject missing values
logit = -3 + 0.02 * (df.age - 40) + (df.plan == "pro") * .8 + (df.plan == "team") * 1.2 + (df.country == "BR") * .5
y = (rng.random(n) < 1 / (1 + np.exp(-logit))).astype(int)

#2. Split first, touch nothing before it

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    df, y, test_size=0.2, stratify=y, random_state=42)   # stratify keeps the 10% positive rate

The test set is locked away until the very end. Every decision (model, hyperparameters, threshold) is made with the training data and cross-validation.

#3. Build the preprocessing + model pipeline

from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression

num, cat = ["age", "income"], ["plan", "country"]

pre = ColumnTransformer([
    ("num", Pipeline([("imp", SimpleImputer(strategy="median")),
                      ("sc", StandardScaler())]), num),
    ("cat", OneHotEncoder(handle_unknown="ignore"), cat),   # unseen category at predict time → all zeros, no crash
])

clf = Pipeline([("pre", pre),
                ("model", LogisticRegression(max_iter=1000, class_weight="balanced"))])

Why a pipeline? One object holds every step, so clf.fit(X_train, y_train) and clf.predict(new_df) do the same preprocessing, and cross-validation refits the imputer and scaler inside each fold. No leakage.

#4. Validate with cross-validation

from sklearn.model_selection import StratifiedKFold, cross_validate

cv = StratifiedKFold(5, shuffle=True, random_state=42)
res = cross_validate(clf, X_train, y_train, cv=cv,
                     scoring=["roc_auc", "average_precision"])
print(res["test_roc_auc"].mean(), res["test_average_precision"].mean())

With a 10% positive rate, average precision (PR-AUC) is the more honest number. A random model scores about 0.10 on it, versus 0.50 for ROC-AUC. Always compare against that baseline. See ROC-AUC vs PR-AUC.

#5. Tune hyperparameters

Step names are the key: model__C means "parameter C of the step named model".

from sklearn.model_selection import GridSearchCV

grid = GridSearchCV(clf, {"model__C": [0.01, 0.1, 1, 10]},
                    cv=cv, scoring="average_precision", n_jobs=-1)
grid.fit(X_train, y_train)
print(grid.best_params_, grid.best_score_)
best = grid.best_estimator_            # already refit on all of X_train

For larger spaces use RandomizedSearchCV(..., n_iter=30). It is usually as good for far less compute.

#6. Try a stronger model

Gradient boosting handles missing values natively and needs no scaling, but still needs categoricals encoded in this setup.

from sklearn.ensemble import HistGradientBoostingClassifier

gb = Pipeline([("pre", pre), ("model", HistGradientBoostingClassifier(random_state=0))])
print(cross_validate(gb, X_train, y_train, cv=cv, scoring="average_precision")["test_score"].mean())

Compare it to the linear model on the same folds and metric. On small or mostly linear data, the simple model often wins, which is a legitimate result.

#7. Choose the decision threshold (on training data, not test)

predict() uses 0.5, which is rarely right for imbalanced problems. Pick the threshold from out-of-fold predictions so the test set stays untouched:

from sklearn.model_selection import cross_val_predict
from sklearn.metrics import precision_recall_curve

oof = cross_val_predict(best, X_train, y_train, cv=cv, method="predict_proba")[:, 1]
p, r, t = precision_recall_curve(y_train, oof)
f1 = 2 * p * r / (p + r + 1e-12)
thr = t[np.argmax(f1[:-1])]              # or choose by business cost instead of F1

If a false negative costs more than a false positive, pick the threshold that minimizes expected cost rather than maximizing F1.

#8. Final evaluation on the test set (once)

from sklearn.metrics import roc_auc_score, average_precision_score, classification_report

proba = best.predict_proba(X_test)[:, 1]
print("AUC", roc_auc_score(y_test, proba), "AP", average_precision_score(y_test, proba))
print(classification_report(y_test, proba >= thr))

If this number is much worse than the cross-validation score, suspect leakage or a distribution shift between train and test.

#9. Calibrate if you need real probabilities

class_weight="balanced" distorts predicted probabilities. If downstream code treats the score as a probability (expected value, risk), recalibrate:

from sklearn.calibration import CalibratedClassifierCV

cal = CalibratedClassifierCV(clf, method="isotonic", cv=5).fit(X_train, y_train)
cal.predict_proba(X_test)[:3, 1]

Use method="sigmoid" when the data is small (isotonic overfits). See Calibration.

#10. Inspect and save

import joblib

names = best.named_steps["pre"].get_feature_names_out()   # num__age, cat__plan_pro, ...
coefs = best.named_steps["model"].coef_[0]                # linear-model feature effects

joblib.dump(best, "model.joblib")                          # saves preprocessing + model together
model = joblib.load("model.joblib")
model.predict(X_test.iloc[:3])

Because the pipeline is saved as one object, serving code cannot forget a preprocessing step. Load a saved model only from sources you trust, and with the same scikit-learn version it was saved with.

#Cheat list of mistakes this workflow prevents

  • Fitting a scaler or imputer on all data before splitting (leakage).
  • Reporting accuracy on a 10% positive problem.
  • Tuning the threshold or hyperparameters on the test set.
  • Forgetting stratify=y and getting a split with almost no positives.
  • A crash in production on an unseen category (handle_unknown="ignore").
