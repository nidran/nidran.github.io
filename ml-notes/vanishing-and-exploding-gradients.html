Vanishing & Exploding Gradients

Say it in 30s: Deep nets multiply Jacobians layer by layer. If typical singular values are below 1, gradients shrink exponentially in depth (vanishing—early layers don't learn); above 1, they explode (NaNs, unstable training). Saturating activations (sigmoid/tanh) vanish; ReLU helps but dead neurons and poor init still hurt. Fixes: He/Xavier init, residuals, normalization, gradient clipping, and shallower paths for signal.

Key points

  • Backprop through depth LLL roughly scales like ∏l=1L∂h(l)∂h(l−1)\prod_{l=1}^L \frac{\partial h^{(l)}}{\partial h^{(l-1)}}∏l=1L​∂h(l−1)∂h(l)​—spectral norm of per-layer Jacobians matters.
  • Vanishing: sigmoid derivative ≤1/4\le 1/4≤1/4; tanh saturates with derivative →0\to 0→0 at large ∣x∣\vert x \vert∣x∣; deep MLPs with either stall. Exploding: large weights + deep chain → overflow.
  • He (ReLU): Var(W)=2/nin\mathrm{Var}(W) = 2/n_{\text{in}}Var(W)=2/nin​; Xavier (tanh/sigmoid): 2/(nin+nout)2/(n_{\text{in}}+n_{\text{out}})2/(nin​+nout​).
  • Residual: h(l+1)=h(l)+F(h(l))h^{(l+1)} = h^{(l)} + F(h^{(l)})h(l+1)=h(l)+F(h(l)) gives a gradient highway through identity.
  • clip_grad_norm_(params, max_norm) caps global norm before the optimizer step—standard in RNNs and LLM training.

Common follow-ups / traps

  • "Is ReLU enough?" → Helps a lot but doesn't remove vanishing entirely (dead ReLUs, very deep nets still need residuals + norm).
  • "Clip by value vs by norm?" → Norm clipping preserves direction; value clipping can distort the update vector.
