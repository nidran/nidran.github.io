LLM Eval

#LLM Evaluation Methods

#Automated Metrics (Reference-Based)

  • Exact Match / Token F1 — overlap with gold answer (e.g., SQuAD-style)
  • BLEU — n-gram precision of generated text vs reference
  • ROUGE — n-gram recall of generated text vs reference
  • BERTScore — cosine similarity of contextual embeddings; captures paraphrases better than n-gram methods

#Automated Metrics (Reference-Free)

  • Perplexity — model's surprise at the next token; lower = more fluent, but doesn't measure correctness
  • LLM-as-Judge — stronger model scores outputs on rubric dimensions (helpfulness, accuracy, safety); can be pointwise (rate 1-5) or pairwise (A vs B)

#RAG-Specific Evals

  • Faithfulness / Groundedness — does the answer follow from retrieved context, or is it hallucinated?
  • Context Relevance — did the retriever pull chunks that actually contain the answer?
  • Answer Relevance — does the response address the question asked?
  • Retrieval Metrics — Recall@k, MRR, NDCG on the retrieval step alone

#Agent-Specific Evals

  • Task Completion Rate — did the agent accomplish the end goal?
  • Tool Use Accuracy — right tool, right arguments?
  • Planning Quality — sensible task decomposition vs going in circles?
  • Failure Mode Categorization — hallucination, retrieval miss, planning failure, tool misuse (track rates of each)
  • Step Efficiency — solved in 3 steps or 15?
  • Trajectory Evals — evaluate the full action sequence, not just the final answer

#Human Evals

  • Side-by-Side Preference — show two outputs, pick the better one (basis for RLHF)
  • Likert Scale Ratings — rate helpfulness, accuracy, tone on 1-5
  • Red Teaming — adversarial probing for safety, jailbreaks, prompt injection
  • Domain Expert Review — subject matter experts judge real-world usefulness

#Benchmarks

  • MMLU, HellaSwag, ARC — general knowledge and reasoning
  • HumanEval, MBPP — code generation
  • GSM8K — math reasoning
  • MT-Bench — multi-turn conversation quality

#Evaluating the Judge (Meta-Evaluation)

  • Human Agreement — Cohen's Kappa, Spearman/Kendall rank correlation against human labels
  • Position Bias Test — swap order of A/B; verdict should stay the same
  • Verbosity Bias Test — does the judge prefer longer responses regardless of quality?
  • Self-Preference Bias — does GPT-4 prefer GPT-4 outputs, Claude prefer Claude?
  • Test-Retest Reliability — same input multiple times; score should be stable
  • Inter-Judge Agreement — multiple LLM judges; disagreements flag hard cases for human review
  • Adversarial Probes — known-answer pairs, injected subtle errors, rubric sensitivity checks
  • Stratified Analysis — break down accuracy by difficulty, domain, failure type
