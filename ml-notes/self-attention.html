Self-Attention

Say it in 30s: Self-attention lets every token attend to every other token in one parallel step: each position builds query, key, and value vectors; scores are dot products scaled by 1/dk1/\sqrt{d_k}1/dk​​, softmaxed into weights, and used to mix values. There is no hidden state carried forward in time — the "memory" of the sequence lives entirely in those pairwise weights.

Key points

  • Shapes: Q,K,V∈Rn×dQ,K,V \in \mathbb{R}^{n \times d}Q,K,V∈Rn×d; attention output is n×dn \times dn×d.
  • Scaled dot-product: softmax(QK⊤/dk)V\mathrm{softmax}(QK^\top / \sqrt{d_k})Vsoftmax(QK⊤/dk​​)V; scaling keeps logits near unit variance as dkd_kdk​ grows.
  • Causal mask (decoder): set future positions to −∞-\infty−∞ before softmax so position iii only sees ≤i\le i≤i.
  • Padding mask: zero out padded positions in keys so they are never attended to.
  • Parameter cost per layer (single block): four d×dd \times dd×d projections → 4d24d^24d2 (biases optional in the count).

Common follow-ups / traps

  • "Why divide by dk\sqrt{d_k}dk​​?" → dot products of dkd_kdk​-dim random vectors have variance ≈dk\approx d_k≈dk​; scaling avoids softmax saturation.
  • "Self-attention vs cross-attention?" → self: Q,K,VQ,K,VQ,K,V from same sequence; cross: QQQ from decoder, K,VK,VK,V from encoder (e.g. Transformers & Attention in encoder-decoder stacks).
  • "Complexity?" → O(n2d)O(n^2 d)O(n2d) in sequence length for the QK⊤QK^\topQK⊤ attention matrix.
