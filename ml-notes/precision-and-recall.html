Precision & Recall

Say it in 30s: Precision = of the things I flagged positive, how many were right (TP / (TP+FP)) — punishes false alarms. Recall = of the actual positives, how many did I catch (TP / (TP+FN)) — punishes misses. They trade off as you move the decision threshold.

When to favor which

  • Recall when missing a positive is costly: cancer screening, fraud, safety.
  • Precision when a false alarm is costly: spam filters, recommending an expensive action.
  • F1 = harmonic mean of the two, for a single number when you care about both.

The threshold link

  • Lower threshold → more positives → higher recall, lower precision. Raise it → the reverse.
  • This is why you report the PR curve, not a single point, on imbalanced problems.

The math

From the confusion matrix (TP, FP, FN, TN):

P=TPTP+FP,R=TPTP+FN=TPRP = \frac{TP}{TP+FP}, \qquad R = \frac{TP}{TP+FN} = \mathrm{TPR}P=TP+FPTP​,R=TP+FNTP​=TPR

PPP = precision (of predicted positives, how many are correct); RRR = recall (of actual positives, how many you caught). Both move when you change the score threshold.

Traps

  • Accuracy is misleading under class imbalance (99% negatives → predict all-negative scores 99%).
  • Precision/recall ignore true negatives by design — that's the point.
